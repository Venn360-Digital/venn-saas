# Referências visuais

Material de consulta, não é o design system deste projeto. O design system do
OdontoBox360 está em `DESIGN.md` na raiz, e sua face visível é a rota
`/design-system` no app — que não pode divergir do código porque é o código.

## `implante-ja-bh-design-system.html`

Pattern library em Elementor/WordPress da **Implante Já BH** — outra clínica,
outro produto. Foi a referência de partida para a paleta e a tipografia do
OdontoBox360: dela vêm a família cromática azul/menta, a escolha de Open Sans e
a escala tipográfica documentada.

O que **não** transfere: a camada de componentes é de marketing (CTA, icon box,
ribbon, hero de duas colunas, star rating) e não tem nada sobre tabela, formulário,
chat ou densidade de dados — o que um app operacional precisa.

Estava em `public/`, onde teria sido servido como página pública no domínio do
OdontoBox360 assim que alguém o commitasse.
