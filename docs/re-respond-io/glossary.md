# Glossary

Vocabulário próprio do respond.io. Definições de `[doc SRC-004]` (glossário oficial), salvo indicação. A observar no produto quando marcado.

| Term | Definition | Evidence |
|---|---|---|
| Organization | Conjunto de usuários da mesma empresa que compartilham uma assinatura. Contém Workspaces. | [doc SRC-004] |
| Workspace | Sub-conta independente dentro de uma Organization (dados, canais e usuários próprios). No app, a rota é `/space/:id/*`. | [doc SRC-004] |
| User | Pessoa com acesso a um Workspace. | [doc SRC-004] |
| Team | Grupo de usuários com objetivo comum (p.ex. roteamento). | [doc SRC-004] |
| Contact | Pessoa que interagiu com um Channel conectado à plataforma. | [doc SRC-004] |
| Conversation | A interação entre um Contact e a plataforma (aberta/fechada). | [doc SRC-004] |
| Message | Comunicação escrita enviada de/para um Contact por qualquer Channel. | [doc SRC-004] |
| Channel | Meio de mensagem conectado para receber/enviar (WhatsApp, IG, etc.). | [doc SRC-004] |
| Inbox (Messages) | Módulo onde os usuários gerenciam todas as conversas. | [doc SRC-004] |
| Custom Inbox | Coleção de Contacts/conversas baseada num conjunto de critérios. | [doc SRC-004] |
| Assignee | Usuário a quem um Contact está atribuído. | [doc SRC-004] |
| Assignment | Ação de atribuir um Contact a um usuário. | [doc SRC-004] |
| Lifecycle | Feature que acompanha Contacts pelos estágios do processo de vendas (o "pipeline"/"negócios"). | [doc SRC-004] |
| Lifecycle Stage | Etapa do funil. Defaults: New Lead → Hot Lead → Payment → Customer; perdido: Cold Lead. Até 20 stages. | [doc SRC-016] |
| Segment | Grupo salvo de Contacts filtrado por critérios (módulo Contacts). | [doc SRC-004] |
| Contact Field | Atributo que coleta fatos sobre Contacts relevantes ao negócio. | [doc SRC-004] |
| Tag | Atributo manual para agrupar Contacts. | [doc SRC-004] |
| Contact Search | Filtro para buscar/ordenar Contacts nos Inboxes. | [doc SRC-004] |
| Workflow | Construtor visual para automatizar processos. | [doc SRC-004] |
| Workflow Trigger | Evento que inicia um Workflow. | [doc SRC-010] |
| Workflow Step | Bloco de ação do Workflow (Send Message, Branch, Assign To...). | [doc SRC-010] |
| Broadcast | Transmitir conteúdo a um grupo de Contacts por um Channel. | [doc SRC-004] |
| AI Agent | Assistente automatizado que lida com conversas de clientes. | [doc SRC-004] |
| AI Assist | Ferramenta no Inbox que gera sugestões de resposta a partir de knowledge sources. | [doc SRC-004] |
| AI Prompts | Ações de IA sobre texto no Inbox (reescrever, traduzir...). | [doc SRC-008] |
| AI Skills | Ações executáveis por um AI Agent (atribuir, fechar, atualizar lifecycle/field). | [doc SRC-007] [doc SRC-018] |
| Knowledge Source | Conteúdo (PDFs, URLs, Snippets) usado por AI Agents e AI Assist. | [doc SRC-004] |
| Snippet | Template de mensagem para respostas padronizadas (canned responses). | [doc SRC-004] |
| Comment | Nota interna numa conversa, invisível ao cliente. | [doc SRC-004] |
| Closing Notes | Resumo de conversa informado pelo usuário ao fechar. | [doc SRC-004] |
| CSAT | Pesquisa de satisfação pós-conversa. | [doc SRC-004] |
| Sentiment | Rótulo de conversa fechada: Positive/Neutral/Negative. | [doc SRC-018] |
| Dynamic Variables | Placeholders que puxam dados do Contact para mensagens no envio. | [doc SRC-004] |
| Growth Widget | Widget embutível no site para visitantes iniciarem conversa. | [doc SRC-004] |
| Integration | Conexão ativa com produto terceiro. | [doc SRC-004] |
| Copilot | Assistente de uso/onboarding da plataforma. | [doc SRC-003] |
| MAC (Monthly Active Contact) | Contato com quem houve conversa no mês — unidade de cobrança. | [doc SRC-017] |
